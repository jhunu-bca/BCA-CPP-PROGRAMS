# BCA - C++ Programs
Practicing C++ programs from basics to advanced 🚀

## 📚 About
This repository contains my C++ programming practice from BCA 1st Year. Currently in BCA 2nd Year - revising and building advanced concepts.

## 📂 Programs List
1. **Swapping Two Numbers**
   - File: `Swapping_two_nums.cpp`
   - Concept: `iostream`, `variables`, `temp variable swapping`
   - Description: Swaps two numbers using a third variable.

2. **Basic Arithmetic Operations**
   - File: `basic_arithmetic_operations.cpp`
   - Concept: `iostream`, `variables`, `arithmetic operators`, `type casting`, `if-else statement`
   - Description: Take 2 numbers as input and prints sum, substraction, multiplication, division and modulus. Handles divided by 0 error.

3. **Factorial Using Recursion**

   - File: `factorial_of_a_number.cpp`
   - Concept: `iostream`, `variables`, `function`, `recursion`, `if-else statement`
   - Description: Takes a number as input and prints its factorial using a recursive function. Base case is 0 and 1 returns 1.
